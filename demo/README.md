# Demo checklist

Use a consenting participant or an appropriate public-domain/public-figure image.

## Recording

1. Show `data/input.jpg`.
2. Run:
   `python -m src.main --image data/input.jpg --tamper-test`
3. Let the program show face detection.
4. Show the live Google Lens result.
5. Show the dynamically selected source URL.
6. Show candidate face distance.
7. Show SHA-256.
8. Show Sepolia transaction hash.
9. Open the Sepolia explorer URL.
10. Show `VERIFIED`.
11. Show `TAMPERING DETECTED`.

Do not reveal `.env` or the private key during the recording.
